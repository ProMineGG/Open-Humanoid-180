# Литьё алюминия в домашних условиях — Open-Humanoid-180

> **Статус:** в разработке.
>
> Пошаговое руководство по литью алюминиевых деталей (корпусов редукторов, кронштейнов) в самодельной печи.

## Планируемое содержание

- Устройство угольного горна (печи) на основе имеющейся конструкции.
- Плавка алюминиевого лома (профили, банки, литьё).
- Раскисление расплава: использование соли и соды для удаления оксидов.
- Изготовление песчаных форм (тип песка, связующее, уплотнение).
- Заливка и извлечение отливок.
- Финишная обработка на токарном/фрезерном станке (подрезка, сверление).
