# Backyard Aluminium Casting — Open-Humanoid-180

> **Status:** work in progress.
>
> Step‑by‑step guide for casting aluminium parts (reducer housings, brackets) in a homemade furnace.

## Planned Content

- Coal‑fired furnace (forge) setup using the existing construction.
- Melting aluminium scrap (profiles, cans, cast parts).
- Degassing the melt: using salt and soda to remove oxides.
- Sand mould making (sand type, binder, ramming technique).
- Pouring and part extraction.
- Finishing on a lathe / milling machine (turning, drilling).
