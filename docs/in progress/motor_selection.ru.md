# Расчёт приводов — Open-Humanoid-180

> **Статус:** в разработке.
>
> Этот документ будет содержать полный расчёт приводной системы робота.

## Планируемое содержание

- Выбор KV для каждого типа мотора (6384, 5065, 3205) с обоснованием.
- Расчёт моментов на каждом суставе с учётом веса робота (~50 кг).
- Определение требуемой редукции для мощных (1:100), средних (1:65) и базовых (1:40) суставов.
- Проверка запаса по току для выбранных драйверов (ODrive, платы гироскутеров, SimpleFOCMini).
- Оценка пиковых и продолжительных нагрузок в режиме ходьбы.

## Когда будет заполнен

Документ будет завершён после:
1. Построения полной CAD-модели робота.
2. Проведения расчётов кинематики и динамики в Gazebo или MATLAB.
3. Тестирования первого прототипа сустава на стенде.
