# Запасные варианты компонентов — Open-Humanoid-180

> **Статус:** в разработке.
>
> Бюджетные альтернативы и запасные варианты на случай недоступности основных компонентов.

## Планируемое содержание

- Замены для моторов 6384 / 5065 / 3205 (другие KV, другие производители).
- Альтернативы для ODrive3.6 (VESC, MKS XDrive, DIY).
- Замена плат гироскутеров (другие ESC с FOC).
- Альтернативные энкодеры (AS5047, TLE5012 вместо MT6826S).
- Замена материалов: PA12‑CF → PETG+CF, алюминий → сталь/печать.
- Где брать компоненты дёшево (разборка старых роботов-пылесосов, электросамокатов).

## Статус

Документ будет заполняться по мере:
- Тестирования альтернативных компонентов.
- Выявления дефицита или дороговизны основных позиций.
