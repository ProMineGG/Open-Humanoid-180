# Проектирование волнового редуктора с ПТК — Open-Humanoid-180

> **Статус:** в разработке.
>
> В этом документе будут описаны инженерные детали самодельного двухступенчатого волнового редуктора с промежуточными телами качения (роликами).

## Планируемое содержание

- Геометрия эллиптического кулачка (генератора волн) для каждой редукции (1:100, 1:65, 1:40).
- Размеры и выбор стальных роликов (от подшипников) в качестве тел качения.
- Расчёт профиля беговых дорожек жёстких обойм.
- Конструкция сепаратора (печать из PA12‑CF).
- Допуски сборки и рекомендуемые зазоры.
- Материалы: алюминиевое литьё vs. печать PA12‑CF.
