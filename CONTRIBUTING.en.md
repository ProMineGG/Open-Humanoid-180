# Contributing to Open-Humanoid-180

Thank you for your interest in the project! Any help is welcome.

## How to help

- Review schematics and calculations — open an Issue if you spot an error.
- CAD modelling — we need assemblies for limbs (legs, arms, torso).
- Programming — ESP32-S3, GD32F303, CAN bus, FOC.
- Documentation — improve README, translations, diagrams, guides.
- Testing — if you have components, share your results.

## Workflow

1. Open an Issue describing what you want to do.
2. Fork the repository.
3. Make changes in your fork.
4. Submit a Pull Request with a description of your changes.

## Communication

All discussions are held via Issues and Discussions.
