# Внесение вклада в Open-Humanoid-180

*Читать на других языках: [English](CONTRIBUTING.en.md)*

Спасибо за интерес к проекту! Любая помощь приветствуется.

## Как помочь

- Проверка схем и расчётов — откройте Issue, если заметили ошибку.
- CAD-моделирование — нужны сборки конечностей (ноги, руки, корпус).
- Программирование — ESP32-S3, GD32F303, CAN-сеть, FOC.
- Документация — улучшение README, переводы, схемы, руководства.
- Тестирование — если у вас есть компоненты, поделитесь результатами.

## Процесс работы

1. Откройте Issue с описанием того, что хотите сделать.
2. Сделайте форк репозитория.
3. Внесите изменения в своём форке.
4. Отправьте Pull Request с описанием изменений.

## Связь

Все обсуждения ведутся через Issues и Discussions.
